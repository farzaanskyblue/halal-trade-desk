# Halal Trade Desk

A simple page that tracks halal-screened stocks and explains, in plain English, whether each one is in a buy zone, a wait, or a hold off.

- `index.html` is the page.
- `data.json` holds the prices, the market note and the write-up for each stock. Claude refreshes it on weekday mornings.
- Live prices are optional. Paste a free Finnhub key into Settings on the page. The key stays in your browser and is never saved here.

This is a planning aid. It is not financial advice or a religious ruling.
